# Запити для реалізації Conway's Game of Life

## Крок 1. Каркас

**Запит:**

Мені потрібно реалізувати Conway's Game of Life мовою Python і написати тести на pytest. Додай `requirements.txt`. Гра відбувається на торі: краї поля з'єднані (wrap-around). Розділи програму на функції у `src/game.py`: `parse_input`, `get_next_cell_state`, `get_next_board_state`, `format_output`, `play_generations`. На цьому етапі створи лише порожні функції з docstring, без логіки. Працюй за підходом TDD.

## Крок 2. Правила клітинки та тор

**Запит:**

Почнімо з `get_next_cell_state`. Спочатку створи для неї модульні тести у `tests/test_game.py`. Перевір правила гри: коли клітинка помирає, виживає або народжується. Обов'язково перевір wrap-around: сусідів у кутах і на краях, зокрема по діагоналі. Після тестів реалізуй функцію так, щоб вони проходили.

## Крок 3. Покоління та відомі фігури

**Запит:**

Тести ядра готові. Тепер реалізуй `get_next_board_state` і `play_generations`. Перевір, що початкове поле не змінюється. Додай тести для фігур block, blinker (зміна орієнтації) і glider (зсув на (1, 1) за чотири покоління, з переходом через край тора). Також перевір порожнє поле та нуль поколінь. Спочатку напиши тести, потім код.

## Крок 4. Введення та виведення

**Запит:**

Реалізуй `parse_input` і `format_output`. Перевір у тестах формат файлу: перший рядок містить кількість поколінь, другий — розміри, далі йде поле. Перевір, що порожні рядки наприкінці файла ігноруються. Обов'язково протестуй неквадратне поле, наприклад 8×5, щоб переконатися, що ширину й висоту не переплутано. Додай інтеграційний тест із `tmp_path`: створи вхідний файл, запусти програму та порівняй вихідний файл з очікуваним результатом.

## Крок 5. CLI та GitHub Actions

**Запит:**

Реалізуй `main.py`, щоб програму можна було запускати командою `python main.py <input> <output>`. Додай GitHub Actions, які запускають тести після push і для pull request. Створи README з інструкціями запуску та місцями для мого ПІБ, групи й посилання на відео.
