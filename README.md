## Інструкція для перевіряючого

Встановлення залежностей (одна команда):

```bash
python -m pip install -r requirements.txt
```

Запуск усіх тестів (одна команда):

```bash
python -m pytest
```

## Запуск програми

```bash
python main.py input.txt output.txt
```

Вхідний файл містить кількість поколінь, ширину й висоту, а далі — рядки поля. `x` позначає живу клітинку, `.` — мертву. Наприклад:

```text
1
5 5
.....
.....
.xxx.
.....
.....
```

Після одного покоління горизонтальний blinker стає вертикальним. Вихідний файл:

```text
.....
..x..
..x..
..x..
.....
```

Поле замкнене в обох напрямках: сусіди клітинки визначаються з урахуванням переходу через протилежний край.
