## Інструкція для перевіряючого

Установка зависимостей (одна команда):

```bash
python -m pip install -r requirements.txt
```

Запуск всіх тестів (одна команда):

```bash
python -m pytest
```

## Run a Program

```bash
python main.py input.txt output.txt
```

Вхідний файл містить число поколінь, ширину та висоту, потім по рядку на кожну строку поля. `x` — жива клітина, `.` — мертва. Наприклад, вхід:

```text
1
5 5
.....
.....
.xxx.
.....
.....
```

После одного поколения горизонтальный blinker становится вертикальным. Выходной файл:

```text
.....
..x..
..x..
..x..
.....
```

Поле замкнуто в обоих напрямках: сусідні позиції обчислюються з переходом через протилежний край.
